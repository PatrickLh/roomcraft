# Spike 人工评分规程（M0-01 / M0-03）

> 机器指标（JSON 可解析、Schema/语义通过）只是**前置门槛**。
> PRD 的「结构可用率 ≥ 80%」「效果图主观可用率 ≥ 60%」必须由人按本规程评分。
> 评分前先定容差与判定口径，评分中途不改口径；存疑样本记录下来集体复核。

## 一、户型解析（Spike A）评分表

对每张真实样本，把 `<sample>.json` 的 `raw` 字段导入原型（或对照图纸）逐项核对：

### 1. 结构正确性（每项 0 / 1）

| 项 | 判定为 1 的条件 |
|---|---|
| 墙体拓扑 | 外墙闭合、内墙分隔与图一致；无缺墙（图上有而 JSON 无）、无多余墙 |
| 房间划分 | 房间数量与名称和图一致（阳台/厨房等不漏判） |
| 门窗完整性 | 门、窗的位置和数量正确，无漏判/错判（门被识别成窗等） |
| 比例正确 | 在 3D/俯视中目测长宽比例与图一致；标定值与图上标注一致 |
| 降级合理 | 飘窗/柱子等按规则降级，未虚构结构 |

### 2. 尺寸容差（按房间抽验 ≥ 3 个）

房间开间/进深与图上标注偏差 ≤ 0.15m 记合格（与 Schema `deviationToleranceM` 一致）。

### 3. 可用判定（二值）

- **可用（1）**：结构正确性 5 项全部为 1，且尺寸抽验全部合格。
  允许存在"小修即可用"的缺陷——小修定义：≤ 2 处墙体微调（拖端点 ≤ 0.3m）或 ≤ 2 处门窗洞补删，
  且**不涉及新增/删除整面墙**。用户手动修正工作量超过此范围即判不可用。
- **不可用（0）**：任何一项结构错误需要重画墙体，或比例失准需要人工重标。

### 4. 错误分类（不可用时必填，供失败模式分析）

`缺墙` `多墙` `墙体错位` `门窗漏判` `门窗错位` `房间名错误` `比例失准` `未标定` `降级失败` `其他`

### 5. 汇总口径

```
电子图结构可用率 = 可用电子图样本数 / 电子图样本数        ← PRD ≥ 80% 按此口径
翻拍图结构可用率 = 可用翻拍图样本数 / 翻拍图样本数        ← 仅记录，不设门槛（M0 风险观察项）
```

样本量小时**同时报告人数与比例**（如 7/10）。10 张样本的结论只用于风险判断，
不能宣称已通过 M4 内测验收（plans/v1.0.md §3 出口门槛）。

## 二、效果图（Spike B）评分表

对每张 `variant` 图，评分人对照【场景截图】与【风格参考图】打分：

| 维度 | 0 分 | 1 分 |
|---|---|---|
| 布局保持 | 房间结构/门窗位置被改变、视角明显不一致 | 布局与场景截图一致 |
| 风格还原 | 看不出风格参考图的影响 | 材质/色彩/家具样式明显来自风格图 |
| 效果说服力 | 明显虚假/扭曲/廉价感，不会分享 | 达到"愿意发给家人看"的水平 |

- **主观可用（1）**：三项全部为 1。
- **主观可用率** = 可用图数 / 总图数（PRD ≥ 60%）。
- 评分 ≥ 2 人独立进行，取一致或多数结果；分歧样本记录进报告。

- 效果图：`spikes/reports/spike-b/scoring.csv`（列：file, 布局, 风格, 说服力, 可用, 评分人）
